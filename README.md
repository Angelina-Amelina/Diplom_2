# Автотесты API для сервиса Stellar Burgers

Данный репозиторий содержит пакет автоматизированных тестов для API космической бургерной **Stellar Burgers**. Тесты написаны на языке **Python** с использованием фреймворка **Pytest** и библиотеки **Requests**. Для генерации наглядных отчетов интегрирован **Allure**.

---

## 🛠️ Технологический стек

* **Язык программирования:** Python 3.10
* **Тестовый фреймворк:** Pytest
* **HTTP-клиент:** Requests
* **Отчетность:** Allure Framework

---

## 📂 Структура проекта

Архитектура проекта:

* `methods/` — изолированный слой API-методов (user_methods.py и order_methods.py), отправляющих HTTP-запросы без лишней логики.
* `tests/` — тестовые сценарии, сфокусированные на проверках ответов бэкенда.
* `tests/conftest.py` — конфигурационный файл Pytest с фикстурами для генерации предусловий (создание, удаление пользователей и получение ингредиентов).
* `helpers/` — утилиты для генерации случайных уникальных данных пользователей и хранения эндпоинтов.
* `data.py` — хранение сообщений об ошибках сервера.
* `requirements.txt` — зафиксированные версии внешних библиотек.
* `allure-report/` — финальный статичный HTML-отчет для ревьюера.

---

## 🚀 Инструкция по локальному запуску

### 1. Подготовка окружения
Клонируйте репозиторий и установите все необходимые зависимости в ваше виртуальное окружение (`venv`):
```bash
pip install -r requirements.txt
```

### 2. Запуск автотестов
Для прогона всех тестов и генерации сырых результатов Allure выполните:
```bash
pytest --alluredir=allure-results
```

### 3. Работа с Allure-отчетами
* Для сборки и **автоматического открытия** интерактивного отчета в браузере:
  ```bash
  allure serve allure-results
  ```
* Для локального просмотра уже сгенерированного отчета, загруженного в репозиторий:
  ```bash
  allure open allure-report
  ```
